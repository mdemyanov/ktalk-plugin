# Lessons Learned

Append-only журнал уроков команды. Пишется по итогам задачи и только тогда, когда урок
переживает эпик; находки об инструментах и API живут в auto-memory, не здесь.

**Компакция.** Когда файл превышает 400 строк — записи старше трёх последних эпиков
переезжают дословно (без переформулировки) в `content/lessons-archive/<тема>.md`, а на месте
записи остаётся одна строка `YYYY-MM-DD — <заголовок> — см. content/lessons-archive/<файл>.md`.
Порог 400 — эвристика, не измерение контекстного бюджета: пересмотри его числом.
