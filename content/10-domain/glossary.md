# Глоссарий

Термины проекта одним файлом.

**Сверка открытых договорённостей** — шаг обработки записи встречи, на котором агент
`ktalk-processor`, до добавления новых строк в секцию профиля «📝 Открытые договорённости»,
сопоставляет уже существующие строки с транскриптом обрабатываемой встречи и обновляет статус
тех, чьё исполнение, отказ или перенос срока прозвучали явно. Не восстанавливает статусы по
артефактам, не относящимся к текущей встрече, и не закрывает строку по умолчанию — см.
`content/30-requirements/2026-08-26-agreements-reconciliation.md`.

**Ревизия строки договорённости** — запись вида `↳ *ревизия {дата}: {что подтвердилось,
источник}*`, добавляемая к тексту существующей строки при сверке; исходный текст и исходная дата
строки при этом не изменяются.

**Канал поставки** — способ, которым потребитель добавляет плагин в Claude Code (маркетплейс с
конкретным адресом репозитория). У плагина `ktalk` два канала: внутренний GitLab-маркетплейс —
источник истины, и публичное GitHub-зеркало — см.
`content/30-requirements/2026-09-04-dual-channel-delivery.md`.

**Зеркало поставки** — канал, копия payload которого создаётся автоматически на релизном теге
источника истины и не принимает обратной синхронизации: правки, влившиеся только в зеркало (issue,
pull request), не попадают в исходное дерево иначе как ручным переносом человеком. Для `ktalk` —
публичный GitHub-репозиторий по отношению к внутреннему GitLab.
